# LUXE STUDIO | Salon Website

A modern, elegant and responsive salon website
built to showcase salon services and provide
a beautiful user experience.

## Live Demo

[View Website](https://luxe-studio-salon-website--r-nikhilesh.replit.app/)

## Features

- Modern and elegant UI
- Fully responsive design
- Smooth animations
- Salon services showcase
- Appointment booking interface
- Mobile-friendly navigation

![Website Screenshot](screenshots/homepage.jpg)

## Installation

1. Clone this repository.
2. Open the project in VS Code.
3. Install dependencies using pnpm install.
4. Run the project using the start command
   specified in package.json.
